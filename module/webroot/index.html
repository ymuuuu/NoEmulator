    Apps ask the GPU driver what it is. On this device it answers with the emulator's name. ANGLE replaces that answer.

    ANGLE is a real translation layer, not a label. It substitutes llvmpipe, and GL_SHADING_LANGUAGE_VERSION still carries an ANGLE git hash. An app on ANGLE can be told it is on ANGLE.
